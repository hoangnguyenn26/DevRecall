# DevRecall demo script

Use the local production deployment at `http://localhost:3000` with the account documented in `DEMO_GUIDE.md`.

1. Open the landing page and explain the Capture → Practice → Plan → Study → Measure loop.
2. Sign in and open Today. Point out the active Study Session as the deterministic next action.
3. Open Weak Topics, inspect the evidence for graph traversal, then follow its Recommendation.
4. Open the current Study Plan and explain its recommendation source, time budget, ordering, and lifecycle.
5. Resume the Study Session. Complete one item explicitly and show that merely opening a resource does not mark it complete.
6. Open Knowledge and edit the Dependency Injection note, then find it again through global search.
7. Complete one due Review with reveal and Again/Hard/Good/Easy keyboard controls.
8. Show an Interview answer version and follow-up, then inspect immutable practice history.
9. Open Number of Islands, record a DSA attempt outcome, and compare it with history. DevRecall does not claim to execute or judge code.
10. Finish at Analytics and explain Review recall outcomes, Interview self-ratings, DSA attempt outcomes, and the next learning insight.

The script intentionally uses only implemented workflows. It does not demonstrate AI evaluation, Mock Interview Sessions, code execution, collaboration, or cloud synchronization.
