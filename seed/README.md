# DevRecall portfolio dataset

`learning-content/` is the approved, importable global catalog. `drafts/` is
review work and is ignored by preview/import unless validation is explicitly
run with `--include-drafts`.

The catalog is deterministic repository data. No runtime AI/provider is used.
See `docs/portfolio-dataset-seeding.md` for the contract and commands.

Do not remove an approved file to delete database content. Archive it explicitly
in source, then use the reviewed importer workflow.
