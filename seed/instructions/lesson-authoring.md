# Lesson authoring

- Use one folder named after the stable slug.
- Keep `content.json` metadata exact and `body.md` readable.
- Declare every Markdown block with `<!-- devrecall-section: <bodyKey> -->` in
  the same order as `sections` in `content.json`.
- Use canonical Domain enum names and canonical topic slugs.
- Review candidate keys describe concepts and remain stable; never use `q1`,
  `q2`, or other positional identity.
- Draft first. Move to `learning-content/lessons/` only after human review.
